# Mustang Settlements

This repository hosts an interactive website for documenting settlements in Mustang District, Gandaki Province, Nepal.

Website: https://zimu-huang.github.io/Mustang/

The website includes three main sections:

- **Background**: a brief introduction to Mustang and an overview map of the surveyed settlements.
- **Settlements**: an interactive catalogue of 85 settlements, including administrative information, regional classification, coordinates, satellite images, and locator images.
- **Image Data**: a multi-source image archive organized by data source and settlement, including iPhone field photos, GoPro survey images, and Google Street View images where available.

Image data are stored under `images/image-data/`. The gallery uses `manifest.json` to index available images and `thumbs/` to load lightweight thumbnails before opening full-size WebP images.
